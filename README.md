Assignment 7: Custom Data Structures in JavaThis repository contains the implementation for Assignment 7 , featuring custom data structures built from scratch in Java under the com.joy.assignment7package.   📂 Project StructureCustomDeque.java: A generic doubly linked list implementation of a Double-Ended Queue (Deque) supporting efficient front and rear insertions ( addFirst, addLast) and removals ( removeFirst, removeLast).   CustomGraph.java: An adjacency list-based undirected graph data structure that supports vertex/edge creation, along with Breadth-First Search (BFS) and Depth-First Search (DFS) traversal algorithms.   Main.java: A driver program that tests and demonstrates the functionality of both CustomDequeandCustomGraph.   🚀 Key FeaturesGeneric Doubly Linked Deque ( CustomDeque<T>)Dynamic size tracking and empty checks.   $O(1)$Time complexity for additions and removals at both ends.   Built-in helper method ( printDeque) to display elements from front to rear.   Graph Traversals ( CustomGraph<T>)Adjacency list representation using a HashMapandArrayList.   Iterative BFS traversal utilizing a Queue and visited Set.   Recursive DFS traversal utilizing helper methods and a visited Set.   🏃 How to RunOpen the project in your preferred Java IDE (such as IntelliJ IDEA).   Navigate to Main.javalocated insrc/main/java/com/joy/assignment7/Main.java.   Run the mainmethod to see the console output for both the custom deque and graph traversal demonstrations.
